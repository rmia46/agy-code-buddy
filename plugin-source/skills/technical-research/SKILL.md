# Technical Research Skill

## 1. Activation Conditions
- Unclear technical problem, architectural decision, or third-party integration requirement.
- Performance optimization or technology selection phase.

## 2. Required Inputs
- Problem statement or comparison targets.
- Constraints (license, performance, runtime, compatibility).

## 3. Step-by-Step Procedure
1. **Literature & Codebase Survey**:
   - Inspect existing solutions and related implementations.
   - Perform web search or API doc retrieval for modern best practices.
2. **Options Analysis**:
   - Evaluate trade-offs (complexity, dependency footprint, maintenance burden, security).
3. **Synthesis & Recommendation**:
   - Synthesize findings into clear pros/cons matrix.
   - Formulate actionable recommendation for Software Architect / Engineering Manager.

## 4. Verification Requirements
- All claims backed by authoritative references, benchmarks, or official documentation.

## 5. Expected Outputs
- Structured research summary or Architectural Decision Record (ADR) draft.

## 6. Failure Handling
- If constraints cannot be satisfied by available options, outline minimal custom design alternative.
